# Real-Data Inputs

This directory contains the processed transcriptomic and metabolomic datasets used for the real-data demonstration of OmicNetR described in the manuscript:

**OmicNetR: An R Package for Interpretable Network-Based Integration of Multi-Omics Data Using Sparse Canonical Correlation Analysis**

## Files

### `RNA_seq_normalised.csv`

Processed and normalized transcriptomic data used as the RNA-seq input for the OmicNetR analysis of the drug induced atopic dermatitis dataset.

### `Metabolomics_raw.csv`

Metabolomics input data used for the corresponding OmicNetR multi-omics integration analysis. Metabolomics preprocessing and transformation steps required for the analysis are implemented in the accompanying real-data analysis script.

## Experimental Groups

The matched dataset comprises 10 samples:

- 5 oleic acid (OA)-treated samples
- 5 diluent (DIL) control samples

The transcriptomic and metabolomic datasets are matched by sample identifier prior to multi-omics integration.

## Reproducing the Analysis

The real-data analysis is implemented in:

`../scripts/02_MC903_real_data_and_figure4.R`

The script performs sample alignment, preprocessing, sparse canonical correlation analysis (sCCA), generation of the individual components used for Figure 3, post-hoc orientation of Component 1 using OA/DIL treatment metadata, statistical comparison of canonical sample scores, construction of directional loading-derived networks, and generation of Figure 4.

The individual Figure 3 outputs generated by the real-data analysis are subsequently compiled using:

`../scripts/03_compile_figure3.R`

## Input Files Required by the Analysis Script

The analysis script expects the following filenames:

`RNA_seq_normalised.csv`

`Metabolomics_raw.csv`

Because the validated analysis script reads these files from the active R working directory, users reproducing the analysis should copy the two input files from this directory into their working directory, or otherwise make them available under these filenames in the active working directory before running the script.

## Interpretation

The MC903 dataset is used as a real-data demonstration of the OmicNetR workflow. The treatment-associated analysis is exploratory because the dataset contains five samples per group.

The OA- and DIL-associated directional networks represent opposite directions of a post-hoc oriented latent canonical component. They should not be interpreted as evidence of differential enrichment, direct molecular interactions, causal treatment effects, or definitive treatment-specific molecular mechanisms.

## Software

The analyses reported in the manuscript were performed using R 4.5.1 and OmicNetR 0.1.1. Additional package versions and computational environment information are documented in the manuscript reproducibility materials and `sessionInfo.txt`.
